# SA Property Management — website rebuild

Static site for SA Property Management Sdn Bhd (Johor Bahru, Kuala Lumpur, Melaka).

- Plain HTML/CSS/JS, no build step needed to serve. Built for GitHub Pages at `/sa-property/`.
- Motion: GSAP (ScrollTrigger, SplitText, CustomEase), Lenis, Swiper — vendored in `assets/vendor/`.
- Fonts: General Sans (Fontshare) and Playfair Display (Google Fonts, OFL), in `assets/fonts/`.
- Map outlines: geoBoundaries (CC BY 4.0).
- The contact form opens the visitor's email app; it needs a form backend before launch.
